# Textos de About para GitHub

Estos campos se configuran en la barra lateral **About** de cada repositorio, no en `README.md`. Las descripciones y topics están listos para que el dueño los copie. No se propone website porque no hay una URL pública de producto aprobada.

## Backend

**Descripción:** API FastAPI de VulnTrack para autenticación, inventario, identificación asistida de productos CPE y consultas CVE a NVD cuando el modo live se habilita en el servidor.

**Topics:** `vulntrack`, `python`, `fastapi`, `postgresql`, `nvd`, `cve`, `cpe`, `cybersecurity`

## Frontend

**Descripción:** Interfaz web React y TypeScript de VulnTrack para gestionar workspaces, dispositivos y aplicaciones, confirmar identificaciones CPE y consultar el historial disponible desde la API.

**Topics:** `vulntrack`, `react`, `typescript`, `vite`, `web-application`, `cpe`, `cybersecurity`

## Database

**Descripción:** Esquema y scripts PostgreSQL de VulnTrack: inicialización, roles, políticas de acceso, datos sintéticos, pruebas y documentación. La lógica de aplicación y las consultas a NVD pertenecen al backend.

**Topics:** `vulntrack`, `postgresql`, `sql`, `database`, `rls`, `cybersecurity`

## Context

**Descripción:** Documentación central de VulnTrack: contexto, requisitos, decisiones, arquitectura, límites de seguridad, auditorías y diagramas compartidos entre repositorios.

**Topics:** `vulntrack`, `documentation`, `architecture`, `cybersecurity`, `project-management`

**Website:** vacío hasta aprobar una URL pública.
