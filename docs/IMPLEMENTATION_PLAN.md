# Plan de implementación

**ESTABLECIDA:** el equipo consta de dos desarrolladores, el plazo aproximado es de cuatro semanas y se prioriza móvil → API → PostgreSQL → web. No se dispone de asignaciones individuales aprobadas.

La siguiente distribución es **PROPUESTA** y requiere aprobación humana; depende de resolver decisiones esenciales antes del trabajo correspondiente:

| Semana | Actividades sugeridas | Estado |
|---|---|---|
| 1 | Acordar tecnologías, contrato mínimo, modelo y límites; preparar el flujo prioritario. | PROPUESTA |
| 2 | Desarrollar registro móvil, envío, persistencia y consulta web del flujo prioritario. | PROPUESTA |
| 3 | Integrar búsqueda y selección de CPE, consulta NVD y presentación de resultados potenciales. | PROPUESTA |
| 4 | Integrar análisis Baseline autorizado, visualización y dashboard; validar el alcance completo. | PROPUESTA |

**PENDIENTE:** aprobación de la distribución, asignación de responsabilidades, dependencias técnicas y criterios de aceptación detallados. El alcance de actualización y eliminación de activos también permanece pendiente.
